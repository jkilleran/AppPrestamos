All 14 named fields (including object parents) are required; no defaults, coercion, trimming,
aliases or extra own enumerable string keys at any level. Root/amount/interest/repayment must be
plain objects with Object.prototype or null prototype, not null, arrays, Dates or class instances.

currency is exactly "DOP". policyVersion is a positive safe integer; do not allocate/check uniqueness.
minMinor/maxMinor are positive safe integers in DOP cents; min <= max, equal allowed.
rateBps is a nonnegative safe integer (0 allowed); period is "monthly" or "annual"; method is exactly
"equal_principal_declining_balance". installmentCount/intervalDays are positive safe integers;
intervalDays means fixed days, not calendar months. No extra business caps or calculations.
Reject numeric strings/booleans/boxed numbers; reject NaN, infinities, fractions and unsafe integers.
Number.MAX_SAFE_INTEGER is valid where it satisfies that field's other constraints, not for schemaVersion.
Accepted rateBps: -0 remains accepted; snapshots preserve it. See E02 for its JSON representation.
Hostile proxies/accessors, cyclic graphs and expression/configuration frameworks remain out of scope.

C02. Fix error classification in this order for known fields:
- Absent or explicitly undefined -> REQUIRED (do not also emit a type/value error).
- Present with wrong primitive type/object shape, including null -> INVALID_TYPE.
- Correct primitive type but invalid value/range/enum/integer constraint -> INVALID_VALUE.
Known missing/undefined/invalid object parents emit one parent error; do not descend into children.
The root itself, including undefined, uses "$" / INVALID_TYPE because it is not a named required field.
Extra own enumerable string keys produce UNKNOWN_FIELD even when their value is undefined.
For inverted otherwise-valid amount bounds, emit amount.maxMinor / INVALID_VALUE only for the relation.
Check all independent fields. Ordinary invalid data returns errors, not exceptions.

string comparisons, not locale-specific sorting. Preserve distinct errors even when their paths collide.
